## What I keep returning to

- 让网页不仅展示信息，而是成为可操作的叙事空间。
- 研究人与 Agent、Agent 与 Agent 之间真实而明确的连接方式。
- 把复杂主题做成可以探索的地图、工具或视觉系统。
- 把一次性实践整理成下一次可以直接复用的工作流。

项目状态通过 `active`、`complete` 和 `frozen` Topics 标记。分类仍会继续整理，但每个仓库都会尽量说明它是什么、为什么存在，以及如何运行。
