# 我是刘行 / chichu，一名跨界 AI 实践者。

我喜欢拆解规则，再用 AI 把自己的理解做成能玩、能用、能体验的东西。从棋类游戏、交互网站到 Agent 硬件，我用原型检验想法，也在真实项目和教学中修正自己的理解。

*AI builder exploring games, interfaces & human–agent interaction.*

我在成都好奇学习社区自主学习，通过一个个具体项目探索自己的方向。

## 我如何思考和创作

**质疑一个规则。** 我喜欢追问：一个游戏最基本的规则是什么？改掉其中一个预设，会发生什么？这种好奇让我把国际象棋和将棋放进同一张棋盘，也成为游戏夏令营里《质疑一个规则》这门课的起点。

**先让想法可以体验。** 为 FCC 搭建 SaaS 时，我开始学习和不同角色沟通需求，先做前端原型，再一起确认流程与权限。原型让我有机会把想象拿出来讨论，也暴露那些只靠口头描述发现不了的问题。

**让创作经验可以传递。** 从自己做游戏到陪零基础的小朋友做游戏，我开始把踩过的坑整理成方法：用 Git 留住好版本，用截图给 AI 清晰的视觉反馈，用任务拆分和 worktree 推进不同功能。教别人创作，也让我重新理解自己的工作方式。

## 代表性实践

### [国象 × 将棋](https://github.com/xing0325/chess-shogi) · 游戏与规则实验

**两套不同的棋类规则，能否在同一张棋盘上相遇？** 我把国际象棋和将棋放进 9×9 棋盘，尝试协调走子、打入与升变等机制，做出了支持本地同屏与联机大厅的融合对战游戏。平衡性仍在探索，部分特殊规则尚未实现。

[查看项目与运行方式 →](https://github.com/xing0325/chess-shogi)

### [KIN](https://github.com/xing0325/kin-hackathon) · Agent × 硬件 × 现实社交

**如果个人 Agent 能在现实空间相遇，它们能如何帮助主人建立连接？** 我发起并主导整体实现，与团队一起探索“发现彼此 → 解释为什么值得认识 → 双方确认 → 留下共享上下文”的流程。比赛原型结合网页界面与 ESP32 实体终端；网页 Demo 展示产品流程，硬件验证状态单独记录。

[体验网页 Demo →](https://xing0325.github.io/kin-hackathon/) · [验证状态](https://github.com/xing0325/kin-hackathon/blob/main/docs/CURRENT.md) · [团队分工](https://github.com/xing0325/kin-hackathon#团队分工)

### [一九四八](https://github.com/xing0325/shannon) · 知识与交互叙事

**抽象的思想，能不能成为一段可以探索的阅读体验？** 我把信息论、控制论与系统论的学习材料重新编排成一本带有 1948 年印刷品气质的交互读本，用章节、图版与动效组织阅读。资料来源和适用边界保留在项目与站内说明中。

[在线阅读 →](https://xing0325.github.io/shannon/)

## 真实场景中的实践

- **商业项目：** 为 FCC 职业规划公司搭建 SaaS，学习跨角色需求沟通、前端原型与权限设计。
- **游戏教学：** 在钥匙玩校 AI 游戏设计夏令营担任特邀玩伴，陪零基础的小朋友从想法走到自己的游戏，也把规则拆解与 AI 协作方法带进课堂。
- **黑客松：** 有参赛与组织协作的双重经历，担任过群核科技空间智能黑客松助教；从自己做出作品，走向帮助更多人完成作品。
