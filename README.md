# 我是刘行 / chichu，一名跨界 AI 实践者。

我喜欢拆解规则，再用 AI 把自己的理解做成能玩、能用、能体验的东西。从棋类游戏、交互网站到 Agent 硬件，我用原型检验想法，也在真实项目和教学中修正自己的理解。

*AI builder exploring games, interfaces & human–agent interaction.*

我在成都好奇学习社区自主学习，通过一个个具体项目探索自己的方向。

## 我如何思考和创作

**质疑一个规则。** 把国际象棋和将棋放在同一张棋盘，或者把“人在地铁间跑酷”改成“地铁在跑酷”：我喜欢从修改预设开始寻找玩法。这也成为游戏夏令营《质疑一个规则》课程的起点。

**先让想法可以体验。** 拾集把整理资料变成逐张判断与批注；真实商业项目让我学会先画流程、做前端原型，再在沟通和测试中修正需求。交互不只是好看，也会影响一个人愿不愿意开始、能不能继续。

**让创作经验可以传递。** 齐马蓝里没有做成的 Blender 尝试，后来用在银饰设计中；自己做游戏踩过的坑，也被整理成版本控制、截图反馈和任务拆分的教学方法。我希望每次创作都留下下次用得上的理解。

## 代表性实践

### [国象 × 将棋](https://github.com/xing0325/chess-shogi) · 从兴趣到规则

**两套棋类规则能否共存？** 我把国际象棋和将棋放进 9×9 棋盘，尝试协调走子、打入与升变，做出支持本地同屏与联机大厅的融合对战。它让我学习在规则之间做具体取舍；平衡性仍在探索，部分特殊规则尚未实现。

### [拾集 pick.](PICK.md) · “皇帝批奏折模拟器”

**整理作品这件事，能不能让人更愿意做？** 我用滑卡、即时批注、待定和撤销，把一大堆资料变成逐张判断的体验，再用导出保留结果。这次我用它筛完了 95 个作品与归档条目。它让我体会到：好的交互既需要轻快的动作，也需要可靠的退路。目前是本地自用原型。

### [KIN](https://github.com/xing0325/kin-hackathon) · Agent 与现实连接

**个人 Agent 能如何帮助主人在现实空间建立连接？** 我发起并主导整体实现，与团队探索“发现彼此 → 解释为什么值得认识 → 双方确认 → 留下共享上下文”。比赛原型结合网页界面与 ESP32 实体终端；这段经历让我学习协调产品流程、软件与硬件，后来继续探索 Deota 协作方向。

[网页 Demo](https://xing0325.github.io/kin-hackathon/) · [验证状态](https://github.com/xing0325/kin-hackathon/blob/main/docs/CURRENT.md) · [团队分工](https://github.com/xing0325/kin-hackathon#团队分工)

### [AI 银饰探索](https://github.com/xing0325/anima-rings) · 从数字创作到实体工艺

**AI 创作怎样走出屏幕？** 从观察银饰工艺开始，我尝试 AI 建模、品牌视觉与[画册展示](https://github.com/xing0325/jewelry)，并与设计师和制作方交流。之前 Blender 尝试留下的经验在这里得到复用；目前按设计与制作探索呈现，不等同于已经量产。

### [LIXON](https://github.com/xing0325/lixon) · 理解效果为什么成立

**审美能不能变成可积累的方法？** 我把 F1 兴趣带进个人网站，反复尝试流体与微动效，再将参考站研究整理成[拆解记录](https://github.com/xing0325/landonorris-teardown)和[动效库](https://github.com/xing0325/web-anim-cookbook)。从复现效果到理解机制，经验才更容易迁移到下一个页面。

### [小红书图文工作台](https://github.com/xing0325/xiaohongshu-preview) · 把创作过程整理成工作流

**做完一个项目，怎样把过程和收获讲给别人听？** 我把 Agent 生成的 HTML/CSS 卡片接入预览、检查与导出，整理成发布准备流程。这也是我第一次认真打磨 README、获得 GitHub Star 的项目；输出质量和长期使用方式仍值得继续改进。

## 真实场景中的实践

- **真实交付：** 钥匙玩校网站是我的第一个付费 AI 项目；FCC SaaS 让我学习架构、跨角色需求与前端原型沟通；英语活动项目让我认识到反复测试和视觉反馈的重要性。
- **游戏教学：** 在钥匙玩校 AI 游戏设计夏令营担任特邀玩伴，陪零基础的小朋友从想法走到自己的游戏，并将规则拆解与 AI 协作方法带进课堂。
- **共同创作：** 做过黑客松参赛项目，也担任过群核科技空间智能黑客松助教；从自己完成作品，走向帮助更多人完成作品。
